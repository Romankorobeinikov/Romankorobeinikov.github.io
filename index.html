Проекты

PROJECT_001

Устройство гиперспектральной визуализации для оценки гемангиом (v2)

Портативный автономный прибор для количественной оценки инфантильных гемангиом. Гиперспектральный захват 8 каналов (450–939 нм) за ~0.5 с вместо 5 с у предыдущей версии.

Лаборатория биофотоники, Сколтех 2025 — 2026
STM32F103 Raspberry Pi Zero Altium Designer C / HAL Python PWM USB CDC PCB

Задача

  • Сократить время захвата 8 каналов с 5 с до приемлемого
  • Устранить неравномерную подсветку по каналам
  • Добавить подавление зеркальных бликов
  • Заменить модульную электронику (6 плат) и добавить мониторинг батареи

Моя роль

  • Схемотехника и разводка двух плат в Altium Designer
  • Прошивка STM32 (HAL/C): PWM 20 кГц, USB CDC, АЦП батареи
  • Python-приложения для Raspberry Pi (UI + захват + TCP/IP) и ПК
  • Сборка и пайка SMD, вся оптическая верификация

Ключевые решения

  • Pi + STM32: PWM-выравнивание яркости → фиксированные настройки камеры по всем каналам
  • 64 SMD LED × 8 длин волн на 2 кольцах → одинаковая геометрия подсветки
  • Кросс-поляризационная схема (2 линейных фильтра) → подавление бликов
  • Единая двусторонняя PCB с pogo-pin монтажом Pi вместо 6 отдельных плат

Результат

  • Время захвата: 5 с → 0.5 с (×10)
  • Межканальная задержка: 600 мс → 10 мс
  • Количество плат: 6 → 1
  • Добавлен мониторинг батареи, подтверждена равномерность подсветки на гиперкубе ладони
