PROJECT_001

Устройство гиперспектральной визуализации

Система для биофотонических исследований: захват гиперспектральных изображений тканей в реальном времени. Разработан low-level стек на STM32, интегрирован с оптическим модулем, значительно увеличена скорость передачи данных.

Сколтех · Лаб. биофотоники 2025 — 2026
STM32F4 DMA · USB OTG Altium Designer SolidWorks C (HAL/LL) Python Оптика

Задача

  • Захват гиперспектральных данных с высокой скоростью
  • Синхронизация камеры, сканера и источника света
  • Передача потока данных на ПК без потерь

Моя роль

  • Схемотехника и разводка платы (Altium)
  • Low-level прошивка STM32 (HAL + LL + регистры)
  • Интеграция электроники с оптическим модулем
  • Концепт-дизайн системы и архитектура ПО

Ключевые решения

  • DMA-цепочки для zero-copy передачи кадров
  • USB OTG High Speed с кастомным дескриптором
  • Аппаратная синхронизация через TIM + NVIC

Результат

  • Скорость захвата увеличена в несколько раз
  • Рабочий прототип для лабораторных исследований
  • Стабильная работа в непрерывном режиме

usb_dma_stream.c C · STM32 HAL/LL 
/* Инициализация DMA-цепочки для потоковой передачи кадра через USB OTG HS */

#include "stm32f4xx_ll_dma.h"
#include "usbd_cdc_if.h"

#define FRAME_SIZE   (640 * 480 * 2)
#define DMA_CHUNKS   (16)
#define CHUNK_SIZE   (FRAME_SIZE / DMA_CHUNKS)

static volatile uint8_t frame_buf[FRAME_SIZE];
static volatile uint32_t chunk_idx = 0;

void DMA2_Stream1_IRQHandler(void) {
    if (LL_DMA_IsActiveFlag_TC1(DMA2)) {
        LL_DMA_ClearFlag_TC1(DMA2);
        /* Отправляем готовый чанк по USB без копирования */
        CDC_Transmit_HS(
            (uint8_t*)&frame_buf[chunk_idx * CHUNK_SIZE],
            CHUNK_SIZE
        );
        chunk_idx = (chunk_idx + 1) % DMA_CHUNKS;
    }
}
