PROJECT_001

Устройство гиперспектральной визуализации для оценки гемангиом (v2)

Портативный автономный прибор для количественной оценки прогрессирования доброкачественных опухолей у младенцев. Гиперспектральный захват 8 каналов (450–939 нм) за ~0.5 с вместо 5 с у предыдущей версии.

Лаборатория биофотоники, Сколтех 2025 — 2026
STM32F103 Raspberry Pi Zero Altium Designer C / HAL Python PWM USB CDC PCB

Задача

  • Сократить время захвата 8 каналов с 5 с до приемлемого
  • Устранить неравномерную подсветку по каналам
  • Добавить подавление зеркальных бликов
  • Заменить модульную электронику (6 плат) и добавить мониторинг батареи

Моя роль

  • Схемотехника и разводка двух плат в Altium Designer
  • Прошивка STM32 (HAL/C): PWM 20 кГц, USB CDC, АЦП батареи
  • Python-приложения для Raspberry Pi (UI + захват + TCP/IP) и ПК
  • Сборка и пайка SMD, вся оптическая верификация

Ключевые решения

  • Pi + STM32: PWM-выравнивание яркости → фиксированные настройки камеры по всем каналам
  • 64 SMD LED × 8 длин волн на 2 кольцах → одинаковая геометрия подсветки
  • Кросс-поляризационная схема (2 линейных фильтра) → подавление бликов
  • Единая двусторонняя PCB с pogo-pin монтажом Pi вместо 6 отдельных плат

Результат

  • Время захвата: 5 с → 0.5 с (×10)
  • Межканальная задержка: 600 мс → 10 мс
  • Количество плат: 6 → 1
  • Добавлен мониторинг батареи, подтверждена равномерность подсветки на гиперкубе ладони

PROJECT_002

УФ-инактиватор патогенов плазмы крови

Медицинский прибор для фотохимической инактивации патогенов в донорской плазме. Светодиодная альтернатива коммерческим системам INTERCEPT/Mirasol — три переключаемых УФ-диапазона (UVA/UVB/UVC), точный контроль дозы в реальном времени, термостабилизация пакета с плазмой.

ООО «ЦБИ КромБио» 2025 — 2026
Arduino Nano C++ UVA / UVB / UVC LED Mean Well ELG TMC2209 MOSFET SolidWorks Altium Designer

Задача

  • Разработать доступный аналог INTERCEPT, Mirasol, THERAFLEX на базе УФ-светодиодов
  • Обеспечить переключение между тремя диапазонами УФ (UVA/UVB/UVC)
  • Реализовать точный контроль дозы облучения

Моя роль

  • Полный цикл: от ТЗ и литобзора до прототипа и КД
  • Расчёт и подбор 186 УФ-светодиодов (26 UVA + 100 UVB + 60 UVC)
  • Схемотехника: Arduino + Mean Well ELG + MOSFET-переключение
  • Механика перемешивания (NEMA 14 + TMC2209), прошивка C++, 3D-модель корпуса

Ключевые решения

  • Единый токовый драйвер Mean Well ELG-100-C1400DA + N-MOSFET переключение групп — три длины волны на одном драйвере
  • Алюминиевая PCB как теплоотвод для 186 SMD LED
  • Накопительный расчёт дозы через фотодатчик в реальном времени на МК
  • Активное охлаждение светодиодной матрицы

Результат

  • Полная техническая спецификация и рабочий прототип
  • Нагрев плазмы <1°C за процедуру
  • Диапазон доз 0.2–6.5 Дж/см²
  • Время обработки 5–20 мин

PROJECT_003

Автоматизация предметного столика лабораторного микроскопа

Система автоматизации XY-перемещения предметного столика оптического микроскопа для автоматизированного подсчёта эритроцитов крови. Шаг перемещения до 5 мкм — точность недостижимая вручную. Полный цикл: механика в SolidWorks, печать на FDM, электроника, прошивка STM32, Python-интерфейс.

ООО «НЭТ» 2025
STM32F411 C / HAL USB CDC TMC2209 NEMA SolidWorks FDM Python PySerial

Задача

  • Заменить ручное сканирование предметного стекла автоматическим XY-перемещением
  • Обеспечить субмиллиметровую точность позиционирования (до 5 мкм)
  • Создать недорогую систему для автоматизированного подсчёта эритроцитов

Моя роль

  • Проектирование механики крепления и привода шестерни в SolidWorks
  • Печать деталей на FDM-принтере, подбор шаговых двигателей с планетарными редукторами
  • Схемотехника и прошивка STM32F411 (HAL/C) с USB CDC
  • Python-интерфейс управления на ПК

Ключевые решения

  • Два шаговых двигателя с планетарными редукторами — шаг перемещения до 5 мкм
  • Драйверы TMC2209 с микрошагом для плавного бесшумного движения
  • STM32F411 Blackpill + USB CDC — подключение к ПК без конвертеров
  • Протокол обмена данными собственной разработки

Результат

  • Рабочий прототип XY-столика, интегрированный в стандартный лабораторный микроскоп
  • Стабильная связка микроконтроллер — ПК — измерительное оборудование
  • Шаг позиционирования 5 мкм при планетарном редукторе

PROJECT_004

Термошейкер для 96-луночного планшета

Лабораторный термошейкер для инкубации 96-луночных планшетов с точным контролем температуры и скорости вращения. Бесколлекторный привод с собственной реализацией трапециевидного FOC и PID-регулятором на STM32F405. Вся силовая и управляющая электроника на одной компактной плате.

Лаб. медтехники in vitro, МФТИ 2023 — 2024
STM32F405 FOC BLDC DRV8313 PID CAN Altium Designer C / HAL PWM DS18B20

Задача

  • Разработать термошейкер для перемешивания и нагрева 96-луночного планшета
  • Точный контроль температуры и скорости вращения
  • Компактная электроника, связь с ПК

Моя роль

  • Полная разработка схемы и PCB в Altium Designer
  • DRV8313PWR, MOSFET для термоплаты, соленоид стопора, DC/DC 24→5В, CAN
  • Прошивка STM32F405 (HAL/C): трапециевидный FOC по датчикам Холла, PID скорости, управление нагревом

Ключевые решения

  • Собственная реализация трапециевидного FOC на таймерах STM32 без сторонних библиотек
  • PID-регулятор скорости и температуры
  • Два DS18B20 для дифференциального контроля температуры планшета
  • Вся система на одной компактной двусторонней PCB

Результат

  • Рабочий прототип с плавным вращением BLDC
  • Стабильная поддержка заданной температуры
  • Стабильная коммуникация с ПК
  • Компактная трассировка всей системы на одной плате
